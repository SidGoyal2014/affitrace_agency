Introduction

RESTful API for Affitrace affiliate tracking platform. Supports Admin, Affiliate, and Advertiser operations.

Base URL: http://82.29.160.75/

Welcome to the Affitrace API documentation. This API provides endpoints for managing affiliate marketing campaigns, tracking clicks and conversions, and generating reports.

The API is organized around REST. All request and response bodies are JSON encoded. Authentication is required for most endpoints using Bearer tokens (Laravel Sanctum).

User Roles

  • Admin: Full platform management (advertisers, affiliates, offers, reports)
  • Affiliate: View assigned offers, tracking URLs, and performance reports
  • Advertiser: Manage their offers and view reports

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {ACCESS_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Authenticate using Laravel Sanctum. First call POST /api/login to obtain an access token, then include it as Bearer {ACCESS_TOKEN} in the Authorization header for protected endpoints.

Authentication

Endpoints for user authentication, token management, and profile retrieval.

Login

Authenticate a user and obtain access and refresh tokens. This endpoint does not require authentication.

Example request:
curl --request POST \
    "http://82.29.160.75/api/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"eai\": \"agency123\",
    \"email\": \"admin@example.com\",
    \"password\": \"password123\",
    \"user_type\": \"admin\"
}"

const url = new URL(
    "http://82.29.160.75/api/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "eai": "agency123",
    "email": "admin@example.com",
    "password": "password123",
    "user_type": "admin"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
